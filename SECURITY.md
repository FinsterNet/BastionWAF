# Security Policy

## Supported Versions

We actively provide security patches and updates for the following versions of Bastion WAF:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is paramount to Bastion WAF. If you discover a security vulnerability, evasion, or bypass in our detection engine, we appreciate your help in disclosing it responsibly.

### How to Report

1. **Do not create a public GitHub issue** for undisclosed security vulnerabilities.
2. Email your findings directly to the maintainers at **robajr14@gmail.com** or open a [Private Security Advisory](https://github.com/FinsterNet/BastionWAF/security/advisories/new) on GitHub.
3. Please include:
   - Vector description and attack category (e.g. SQLi, SSRF, Deserialization, Bot evasion)
   - Step-by-step reproduction instructions or payload sample
   - Expected behavior vs. actual behavior
   - Proposed remediation or patch (if available)

### Response Timeline

- **Initial Acknowledgment**: Within 24-48 hours.
- **Triage & Assessment**: Within 72 hours.
- **Fix & Public Advisory**: Coordinated release following verification and regression testing.

Thank you for helping keep Bastion WAF and its protected applications secure!
