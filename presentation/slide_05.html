Core Defense Pipeline (How It Works)

A multi-stage inspection flow engineered for deep payload de-obfuscation and sub-millisecond execution.

STEP 1
Multi-Pass Normalization Layer
Recursively resolves multi-stage URL encoding, HTML entities, Unicode NFKC homoglyphs, and comment injection techniques (e.g. UNI/**/ON) before any rule evaluation.
STEP 2
Hybrid Inspection Suite
Dual raw and canonical payload representations evaluated concurrently against 28 Core Rule Set (CRS) signatures across OWASP Top 10, API, and Bot threats.
STEP 3
Context-Aware Semantic AST Lexer
Parses structural grammar tokens to evaluate true execution intent and boolean tautologies, rather than relying on flawed blind keyword matching.
STEP 4
Fail-Safe Operation Engine
Configurable Passive Monitor (Bypass) Mode for safe staging, alongside a Fail-Open safety switch to guarantee continuous application availability.
