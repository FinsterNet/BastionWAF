3-Tier Adaptive Bot & Threat Mitigation

Replacing blunt "block-or-allow" walls with human-centric adaptive verification.

Tier 1 • High Risk
High-Confidence Exploits (Score ≥ 70)
Confirmed attacks (SQLi, RCE, Webshells) are dropped instantly at the gateway boundary. No backend application execution occurs, saving origin server compute.
Action: Immediate HTTP 403 Forbidden Drop
Tier 2 • Suspicious
Suspicious Anomalies (Score 40–69)
Suspicious traffic and automated bot scrapers are served an in-house interactive Slider CAPTCHA, verifying human mouse trajectory smoothness and velocity without third-party cloud APIs.
Action: Interactive Slider CAPTCHA Challenge
Tier 3 • Verified Clean
Clean / Human Traffic (Score < 40)
Legitimate users and CAPTCHA-cleared clients receive a cryptographically signed HMAC token (15-min TTL) and are forwarded seamlessly to upstream application servers.
Action: HTTP 200 Forward Upstream
